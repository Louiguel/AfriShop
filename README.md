# AfriShop

AfriShop est un site vitrine consacré aux produits africains.

## Technologies utilisées

- HTML5
- CSS3
- Git
- GitHub Actions

## Fonctionnalités

- Présentation des produits
- Section promotions
- Publication automatique avec GitHub Pages

## Déploiement

Le site est déployé automatiquement sur GitHub Pages grâce à GitHub Actions.
