# AfriShop

AfriShop est un site vitrine consacré aux produits africains.

## Technologies utilisées

- HTML5
- CSS3
- Git
- GitHub Actions

## Fonctionnalités

- Présentation des produits
- Section promotions
- Publication automatique avec GitHub Pages

## Déploiement

Le site est déployé automatiquement sur GitHub Pages grâce à GitHub Actions.

## Publication GitHub Pages

Le déploiement est automatisé avec GitHub Actions.

Chaque push sur la branche main déclenche :
1. La vérification des fichiers HTML et CSS.
2. La préparation du dossier public.
3. La création de l'artefact.
4. Le déploiement sur GitHub Pages.
